# MPay Local

Нативный Android-проект (Java, Android 11 / API 30 и новее), локальный каталог банковских карт. **Это не действующий платёжный кошелёк: APK не оплачивает покупки и не эмулирует банковскую карту.**

Текущая версия — **0.2.0**. Для распространения подготовлена отдельная release-сборка с постоянной подписью и адаптивной иконкой. См. [установку и обновления](RELEASE.md) и [конфиденциальность](PRIVACY.md).

## Реализовано

- Несколько карт, выбор активной карты, редактирование и удаление с подтверждением.
- Категории «Мир», Visa, Mastercard, UnionPay, «Другая». Категория не подтверждает возможность оплаты или действительность карты.
- Ввод полного номера с проверкой контрольной суммы либо только последних четырёх цифр. В хранилище попадают исключительно последние четыре цифры.
- Локальное OCR снимка через встроенную Latin-модель ML Kit: номер, срок, предположение об имени держателя. Все поля можно исправить перед сохранением. Имя кириллицей вводится вручную. Банк автоматически не определяется.
- Системный BiometricPrompt: сильная биометрия либо PIN/пароль/графический ключ блокировки **телефона**. PIN банковской карты приложение не запрашивает.
- AES-GCM, ключ Android Keystore с обязательной недавней системной аутентификацией. Атомарная запись файла в `noBackupFilesDir`; резервное копирование и перенос отключены.
- Автоматическая блокировка при уходе приложения в фон; запрет снимков экрана средствами Android.
- Отдельный ручной журнал расходов по каждой карте. Суммы записываются десятичной строкой без преобразования в `float`; валюта проверяется по ISO 4217. Добавление записи не выполняет оплату.
- Свайп вверх или нажатие на нижнюю полосу открывает выбранную карту **внутри приложения**.
- Русский интерфейс, прокрутка, системные отступы, ограничение ширины содержимого на больших экранах.

## Сборка

Нужны JDK 17, Android SDK 34 и доступ к серверам Gradle, Google Maven / Maven Central для первой сборки. Gradle Wrapper включён в проект. Можно открыть корень проекта в Android Studio Hedgehog и дождаться Gradle Sync. SDK задаётся через `ANDROID_HOME` или `local.properties` (не включать в git). AGP 8.2.2 выбран для совместимости с установленной IDE.

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

APK после успешной сборки: `app/build/outputs/apk/debug/app-debug.apk`. Debug-сборка предназначена для разработки; перед распространением нужна отдельная release-подпись.

Проверено 1 ноября 2026 года: `assembleDebug`, `testDebugUnitTest` и `lintDebug` завершились успешно; 4 теста прошли. В итоговом манифесте APK отсутствует разрешение INTERNET. Проверка debug-подписи через `apksigner` успешна. Проверка на физическом устройстве не проводилась.

## Проверка на телефоне

1. Включить блокировку телефона, установить APK и подтвердить вход. При отмене проверки данные должны оставаться скрытыми.
2. Добавить две карты с различными названиями, переключить выбранную карту; закрыть и открыть приложение, подтвердить сохранение.
3. Заполнить карту по снимку и исправить распознанные поля. Не использовать фотографии оборотной стороны с CVV. Проверить, что после обработки каталог `cache/scan` пуст.
4. Внести по записи в историю каждой карты; убедиться, что истории разделены. Проверить сумму с запятой, неверную валюту, пустое название и нулевую сумму.
5. Перейти в другое приложение и вернуться: MPay должен снова запросить подтверждение. Незавершённая форма после ухода в фон сбрасывается.
6. Смахнуть снизу: отображается выбранная карта и сообщение о неподключённой оплате. Приложение не должно показывать успешное списание.
7. Удалить карту и убедиться, что её ручные записи удалены, а данные другой карты сохранились.
8. Проверить Android 11 и Android 15+, крупный шрифт, альбомную ориентацию, небольшой экран и отсутствие сети. Проверки на физическом устройстве ещё обязательны.

## Данные и ограничения

Сохраняются ID карты, пользовательское название, система, последние 4 цифры, срок, имя держателя и ручные записи. CVV, PIN карты и полный PAN не сохраняются в кошельке. Временный JPEG создаётся в закрытом кэше и удаляется после OCR; при завершении процесса оставшийся файл удаляется на следующем запуске. Внешнее приложение камеры имеет собственную политику хранения. Незавершённый снимок не восстанавливается после уничтожения процесса.

В манифесте явно удалены сетевые разрешения, включая разрешения из библиотек. Модель OCR включена в APK. После сборки следует проверить итоговый merged manifest. Приложение не имеет аналитики, аккаунта или API банков. История не является банковской выпиской. При потере ключа Keystore, удалении приложения или сбросе телефона восстановление данных не предусмотрено. Изменение карточки в MPay не меняет реквизиты у эмитента. Эта версия не проходила независимую проверку безопасности.

## Что нужно для реальных платежей

Универсальная оплата «любой картой во всех странах» без взаимодействия с банками не является выполнимым требованием. Считывание номера и NFC/HCE не извлекает платёжные секреты банковской карты.

Для следующего этапа необходимо выбрать рынки и банков/процессинговых партнёров, согласовать подключение к сервисам токенизации конкретных систем, проверку держателя, выпуск и жизненный цикл токенов, платёжные криптограммы, сертификацию и получение подтверждённых статусов операций. Конкретная архитектура и возможность работы телефона без сети зависят от правил выбранного провайдера. Отсутствие собственной регистрации возможно обсуждать отдельно от необходимой банковской идентификации; отсутствие собственного сервера не отменяет внешнюю платёжную инфраструктуру.
